# Architecture

```text
Maid Brain / Identity
        │
        ▼
Individual Runtime
├─ individual_id
├─ current_state
├─ memory
├─ decision history
└─ lived experience
        │
        ├──────────┬──────────┐
        ▼          ▼          ▼
       LLM        Voice      Body
                              │
                    2D / 3D / Device
```

## 1. 人格と個体は別

同じ人格設定を読み込んでも、それだけでは「以前から一緒にいた同じ個体」にはなりません。

そのため、人格の初期情報とは別に個体IDと継続データを持たせます。

## 2. 記憶と判断も別

記憶は「何が起きたか」。

判断は「その時、何を材料にどう決めたか」。

これらを分けておくことで、後から「なぜその返答や行動になったのか」を追える設計にできます。

## 3. LLMや身体は交換可能

LLMそのものを本人の正本にしないことで、将来モデルを変更しても、個体側の人格・経験・状態を引き継げる構造を目指せます。

画面上の2Dキャラクター、3Dモデル、スマートフォン、将来のロボットなども同様に、同じ個体を表現する外部の身体として扱えます。
